# Smart Light PCB

KiCad hardware project for an ESP32-S3 BLE-controlled AC phase dimmer.

> [!WARNING]
> This project works with **220-230 VAC mains voltage**.
> Assembly, probing, flashing while connected to mains, and load testing require proper isolation, fusing, enclosure, and experience with high-voltage electronics.
> Treat this board as a prototype or lab project, not a certified consumer product.

## Related Repositories

The complete Smart Light project is split into two repositories:

- **PCB / KiCad hardware**: <https://github.com/slipknosha/smart_light_pcb/tree/develop>
- **ESP32-S3 firmware**: <https://github.com/slipknosha/smart_light/tree/develop>

This repository contains the schematic, PCB layout, BOM, 3D export, and manufacturing outputs.
The companion repository contains the ESP-IDF firmware that runs on this board.

## Project Overview

The board is a compact zero-cross synchronized triac dimmer built around an **ESP32-S3-WROOM-1** module.
It is designed to control a 220-230 VAC load using phase-angle dimming, with BLE control handled by firmware.

Main functional blocks:

- ESP32-S3 controller with native USB-C flashing
- Isolated AC/DC 5 V power supply based on Mean Well `IRM-05-5`
- 3.3 V logic rail generated by `LM1117MP-3.3`
- Zero-cross detector using `LTV-814`
- Random-phase optotriac driver using `MOC3052M`
- Main AC switching triac `BTB16-600B`
- BOOT and RESET buttons
- USB ESD protection and CC resistors
- AC input and load terminal blocks

## Firmware Compatibility

Use the firmware from:

<https://github.com/slipknosha/smart_light/tree/develop>

The current firmware expects this exact pin mapping:

| Board net | ESP32-S3 GPIO | Firmware module | Purpose |
|---|---:|---|---|
| `LTV_OUT` | `GPIO1` | `dimmer.c` | Zero-cross detector input |
| `MOC` | `GPIO2` | `dimmer.c` | Triac optodriver control output |
| `ESP_IO0` | `GPIO0` | Boot hardware | Bootloader button |
| `ESP_EN` | `EN` | Reset hardware | Reset / enable |
| `ESP_D-` | `USB_D-` / `GPIO19` | ESP-ROM / USB CDC | Native USB D- |
| `ESP_D+` | `USB_D+` / `GPIO20` | ESP-ROM / USB CDC | Native USB D+ |

The BLE device name is:

```text
SmartLight
```

The firmware exposes a custom BLE service and characteristic for dimming:

```text
Service:        7b5e0001-4c3f-4b3d-9a57-8d47b4ef0001
Characteristic: 7b5e0002-4c3f-4b3d-9a57-8d47b4ef0001
```

The characteristic accepts a binary little-endian unsigned integer in the range:

```text
0..100000
```

Typical nRF Connect writes:

```text
0      -> 00 00 00 00
1000   -> E8 03 00 00
10000  -> 10 27 00 00
50000  -> 50 C3 00 00
100000 -> A0 86 01 00
```

## Hardware Architecture

### Power Input and Rails

The board can receive 5 V from USB-C during development.
For standalone operation, the mains input feeds the isolated `IRM-05-5` AC/DC module.

Power chain:

```text
AC_L / AC_N -> IRM-05-5 -> 5 V -> LM1117MP-3.3 -> 3.3 V logic
```

The 5 V rail includes Schottky diode OR-ing/protection and decoupling capacitors.
The 3.3 V rail powers the ESP32-S3 and the low-voltage optocoupler side.

### Zero-Cross Detector

The zero-cross detector uses:

- `U1` - `LTV-814`
- `R1`, `R2` - 100 k mains-side resistors
- `R8` - 47 k pull-up on `LTV_OUT`

The isolated output is connected to `ESP32-S3 GPIO1` as `LTV_OUT`.
Firmware counts the accepted zero-cross edges and schedules the triac gate pulse relative to each half-cycle.

### Triac Driver

The triac gate path uses:

- `U3` - `MOC3052M` random-phase optotriac
- `Q2` - `BC847B` NPN transistor
- `R10` - 2.2 k base resistor
- `R11` - 100 k base pulldown
- `R3` - 180 ohm gate-side resistor
- `R12` - 330 ohm triac-side resistor
- `Q1` - `BTB16-600B` power triac

The ESP32 drives net `MOC` on `GPIO2`.
The firmware keeps this output low normally and sends a short pulse after each zero-cross delay.

### USB and Programming

The ESP32-S3 is wired for native USB flashing through `J3` USB-C.

USB-related parts:

- `J3` - USB-C receptacle
- `R4`, `R5` - 5.1 k CC resistors
- `U5` - `USBLC6-2SC6` ESD protection
- `SW2` - BOOT button on `ESP_IO0`
- `SW1` - RESET button on `ESP_EN`
- `J4` - 2x3 debug/programming header

The board can be flashed directly over USB without an external USB-UART converter.

## Suggested Bring-Up

1. Inspect the assembled PCB for shorts, solder bridges, and component orientation.
2. Power from USB only; verify 5 V and 3.3 V rails.
3. Confirm ESP32-S3 native USB flashing.
4. Flash the firmware from the companion repository.
5. Confirm BLE advertising as `SmartLight`.
6. Pair/bond from nRF Connect or the Android app.
7. Verify `LTV_OUT` zero-cross logs with mains connected under controlled conditions.
8. Test dimming with a suitable resistive load.
9. Move to real lamp testing only after the low-voltage and isolation checks pass.

## Safety Notes

- Keep the low-voltage USB/debug side isolated from mains during testing.
- Do not touch or probe the board while it is energized from AC.
- Use a safe enclosure and strain relief before any practical use.
- Check creepage/clearance and local electrical requirements before considering real deployment.
- The triac is non-isolated and may require thermal management depending on load current.
